# Blog Application

## Module 3

A full-stack blog application built with HTML, CSS,
JavaScript, Node.js, Express and MangoDB.

## Features

- User registration
- User login
- Create blog posts
- View blog posts
- Dashboard
- Logout
- User.js
- Blog.js

## Technologies

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MangoDB

## API Endpoints

POST /api/register
POST /api/login
POST /api/blogs
GET /api/blogs

## How to Run

1. Open the backend folder
2. Install dependencies
3. Run the server

npm install
node server.js

Server runs on:

http://localhost:5000
