# 📝 Blog Application

A full-stack Blog Application built step-by-step using HTML, CSS, JavaScript, Node.js, Express.js, MongoDB, Mongoose, JWT, and bcryptjs.

This project was developed through five modules, starting from a basic frontend and gradually adding backend APIs, database integration, CRUD functionality, and secure authentication and authorization.

---

## 🚀 Project Overview

The Blog Application allows users to:

- Register an account
- Login securely
- Create blog posts
- View their blog posts
- Edit their own blogs
- Delete their own blogs
- Logout securely

The application uses JWT authentication to identify users and authorization checks to ensure that users can only manage their own blog posts.
